# PresseHelden · Anweisung für v0

Baue die Seite exakt nach dieser Datei. Verbindlich ist `drafts/` (nach der Freigabe `approved/`). Sichtbare Referenzen sind `brands/pressehelden/validation/in-action.html` (komplette Landing Page für Immobilienunternehmen, alle 13 Sections) und `validation/components.html` (alle 30 Komponenten mit Mobilvarianten). Die verbindliche CSS-Quelle ist `validation/ph.css`, das Verhalten steht in `validation/ph-motion.js`. Weiche nicht auf den shadcn-Default aus. Stilvorbild ist pressehelden.com selbst.

## Stack

Next.js App Router, Tailwind CSS v4, shadcn-Primitives nur als Struktur (Dialog, Form). Das Aussehen kommt aus `ph.css`: **Die `ph-*`- und `v-*`-Klassen werden 1:1 übernommen, nicht in Tailwind nachgebaut.** Tailwind ist nur Kleber für Abstände und Ausrichtung innerhalb einer Komponente. Kein `rounded-md` an Buttons (Buttons sind Pillen). Kein radialer Verlauf. Kein Glow. Kein Glas außerhalb von Foto-Sections.

Dateien:

- `validation/ph.css` nach `app/ph.css` kopieren und in `globals.css` nach Tailwind importieren. Block „1 · Fonts“ (die `@font-face`-Regeln) löschen, die Schriften kommen aus `next/font`. `url("assets/…")` wird `url("/ph/…")`
- `validation/assets/` nach `public/ph/` kopieren und mit `next/image` einbinden (Phones, Artikel, Fotos, Logos). Lottie-JSONs und Poster bleiben unter `public/ph/lottie/`
- `ph-motion.js` als Client-Komponente `<PhMotion />` portieren (siehe „Bewegung“). Die `data-*`-Schnittstelle bleibt gleich, damit Markup aus `in-action.html` ohne Umbau funktioniert
- `lottie-web` per `npm i lottie-web` und dynamischem Import (`lottie-web/build/player/lottie_svg`), nur im Client, erst wenn ein `[data-lottie]` in den Viewport kommt

## Schriften

```tsx
import { Geist, Inter } from "next/font/google";

const display = Geist({
  subsets: ["latin"],
  weight: ["400", "600", "700"],
  variable: "--font-geist",
});

const text = Inter({
  subsets: ["latin"],
  weight: ["400", "600", "700"],
  variable: "--font-inter",

```

Beide `variable` an `<html lang="de">` hängen. `<body className="ph-page">`. Geist trägt die Marke: Headlines, Buttons, Nav, Großziffern, Footer-Nav. Inter ist der Erklär-Font: Fließtext, Kennzahlen, Labels, FAQ, Testimonials. Keine dritte Schrift. Keine Kursive.

## Seite, Raster, Schalen

- `<body class="ph-page">`: `--page` plus fixiertes Linienraster `repeating-linear-gradient(90deg, rgba(255,255,255,.4) 0 1.5px, transparent 1.5px 10vw)`. Das Raster ist die einzige Textur
- Jede Section ist eine **Schale** `.ph-shell`: Radius 32 (mobil 24), Abstand zum Viewport und zwischen Schalen `clamp(8px, 1vw, 14px)`, Innenabstand vertikal `clamp(64px, 6vw + 26px, 112px)`, Gutter `clamp(20px, 3vw, 48px)`. Nie randlose Vollbreite-Bänder

- Splits: `.ph-pair` 1/1, `--5-7` (Text/Visual), `--7-5`. Mobil (< 768 px) alles einspaltig, Text zentriert, Visual unter dem Text

### Das Band (`<mark>`)

Das Band ist der Textmarker der Marke und markiert den Nutzen.

- **Genau ein `<mark>` pro Headline.** Text bleibt schwarz, das Band ist `--band`, `padding: .02em .14em`, `box-decoration-break: clone` (jede Zeile einzeln markiert)
- Im H1 ist der Band-Teil der Nutzen, danach regular die Erklärung: „**Mehr Vertrauen bei Eigentümern:** Wir bringen Ihr Maklerbüro in die Presse.“
- In H2 steht das Band am Anfang, in der Mitte oder am Ende: „**In 4 Schritten** zu mehr Markenpräsenz“, „Was unsere **Kunden sagen**“
- Auf Foto-Schalen entfällt die Fläche, nur 700 bleibt (`<strong>` oder `<mark>`, CSS regelt es)
- Im Fließtext höchstens ein Band pro Section, nur auf dem Fazit-Satz (`.ph-body mark`)
- `&nbsp;` gegen Waisen im Band („Platz&nbsp;1 in 6&nbsp;Wochen“)

## Bewegung

Volle Referenz: `drafts/skill/references/motion.md`.

**Grundsätze:** 40-ms-Raster (25 fps wie die Lotties). Jede Bewegung endet in einem Zustand mit Aussage. Genau ein aktives Element pro Wechsel-Komponente. Pause bei Hover, außerhalb des Viewports und bei verstecktem Tab. Kein Bounce, kein Spring, kein Overshoot.

| Token | Wert | Einsatz |
|-------|------|---------|
| `--d-fast` | 240 ms | Hover |
| `--d-base` | 400 ms | Fades, Panels, Card-Grow, FAQ |
| `--d-pop` | 600 ms | Karten-Pop |
| `--d-reveal` | 640 ms | Einblendung |
| `--d-shelf` | 800 ms | Regal, SERP-Tausch |
| `--d-draw` | 1200 ms | Linien zeichnen |
| `--d-count` | 1600 ms | Zähler |
| `--e-enter` | `cubic-bezier(.17,0,0,1)` | Standard rein |
| `--e-shelf` | `cubic-bezier(.85,0,.21,1)` | große Verschiebung |
| `--e-pop` | `cubic-bezier(.333,0,.2,1)` | Karten-Pop |
| `--e-draw` | `cubic-bezier(.17,.17,.67,1)` | Linien |

**`data-*`-Schnittstelle** (in `<PhMotion />` portieren, Markup bleibt gleich):

| Attribut | Verhalten |
|----------|-----------|
| `data-reveal` / `="left"` / `="right"` / `="pop"` | einmalige Einblendung bei 20 % im Viewport, 32 px Weg, 640 ms; `--i` versetzt um 120 ms |
| `data-reveal-stagger` | Kinder 0 / 120 / 240 / 360 ms |
| `data-count` + `data-suffix` | Zahl zählt hoch, 1600 ms `enter` |
| `data-marquee` + `data-speed` + `data-direction` | Endlos-Spur 30 px/s, Kopie `aria-hidden`, ziehbar |
| `data-shelf` + `data-autoplay` | Phone-Regal, 800 ms `shelf`, Autoplay 4000 ms |
| `data-serp` | Ergebnisse tauschen nach 1200 ms (FLIP 800 ms), Sieger bekommt Rand + Pokal |
| `data-type-loop` / `data-type` | Tipp-Effekt 80 ms/Zeichen, Cursor blinkt, Loop |
| `data-rotator` | Zeilen + Bilder, 2500 ms (erster 1500 ms) |
| `data-sequence` + `data-step` | Glas-Cards nacheinander aktiv, danach alle |
| `data-steps` | vier Schritte, ein aktiver |
| `data-testi` + `data-autoplay` | Testimonial-Slider, 5000 ms, Panel 400 ms mit 46 px Versatz |
| `data-lottie` + `data-end-frame` | Lottie laden im Viewport, einmal abspielen bis Endframe |
| `data-play` | `.v-*`-Animation startet im Viewport (Linien, Punkte, Balken) |

**`prefers-reduced-motion: reduce`:** keine laufende Animation. Loops stehen, Reveals sofort sichtbar, Zähler zeigen den Endwert, Lotties springen auf den Endframe, Wechsel-Komponenten zeigen alles (Rotator alle Zeilen schwarz, Schritte alle offen, Glas-Cards alle aktiv), Tipp-Effekte zeigen den vollen Text.

## Copy-Regeln

- Sie-Form überall, außer in wörtlichen Kundenzitaten
- B2B, sachlich-direkt, kurze Sätze, gern als Gegensatz-Paar. Problem zuerst
- Kanäle heißen „Google“, „ChatGPT und Gemini“, „Medien“. Google nie ohne KI, ChatGPT nie ohne Gemini
- Primär-CTA immer „Kostenfreie Potenzialanalyse“
- Zahlen mit Plus oder Prozent, ohne „über“: „500+ Veröffentlichungen“, „95% unserer Kunden“. Ausnahme Originalzitat „über 1.000 € Trafficvalue“
- Medien namentlich nennen. Keine Superlative ohne Beleg („Marktführer“, „Nr. 1“)
- Erlaubte Zahlen: 15+, 500+, 95%, 100+ (vor Livegang belegen), Google 100+ · 5,0 mit Datenstand, Ergebnis-Claims aus `testimonials.md`

## Verboten

- Mehr als ein `<mark>` pro Headline. Mehr als ein Band im Fließtext einer Section. Farbiger Headline-Text
- `#F3AD4F` oder `#EB8700` als Textfarbe. Orange als Text nur `#9A5100`
- Das Rot-Band öfter als einmal pro Seite oder in einer Headline
- Dunkle oder schwarze Section-Flächen. Dunkel nur als Foto mit Scrim
- Glas (`backdrop-filter`) auf Grau oder Weiß
- Randlose Vollbreite-Sections. Jede Section ist eine Schale mit Radius 32
- Radiale Verläufe, Glow, Lichtflecken, Verläufe außerhalb der Liste in `ph.css`
- Rand nur links als aktiver Zustand. Aktiv ist ein voller Orange-Rand, ein Band oder der Halo
- Erfundene Medien, Fantasie-Zeitungslogos, Lorem-Artikel, Platzhalter-Screenshots
- Zahlen ohne Quelle, verallgemeinerte Ergebnis-Claims ohne Medium und Kunde
- Deko-Bewegung (Blobs, Partikel, Dauer-Rotation), Bounce, Spring, Overshoot
- Andere Primär-CTAs als „Kostenfreie Potenzialanalyse“
- Du-Form
- Neue Personenfotos oder Stock-Gesichter außerhalb von Team- und Kundenmaterial
- Badges wie „Neu“, „Top“, „Beliebt“. Eyebrows außer der einen im Hero. Punkte in Pills, Tabs oder Listen
- Icons in gefüllten Kreisen (außer den funktionalen Kreisen oben). Lucide, Heroicons, Emoji
- Erklär-Badges über Gesichtern. Glas-Cards nur im unteren Drittel eines Fotos
- „kostenlos · unverbindlich · in 24 h“-Zeilen
- Google-Badge ohne Link oder ohne Datenstand
- Befüllbare Phones ohne iOS-Statusleiste, Dynamic Island und Home-Indikator
- Inter oder Geist durch eine andere Schrift ersetzen. Kursive
